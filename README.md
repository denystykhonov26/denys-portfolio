# Denys Tykhonov — Portfolio

A responsive editorial portfolio for Denys Tykhonov, focused on web development, automation, and AI-assisted solutions.

## Included pages

- Home page with selected work, an interactive hero, about preview, and contact section
- Projects index
- Intertekhkorm case study
- VSE Homework Agent case study
- About page

## Technology

- Semantic HTML5
- Modular CSS
- Vanilla JavaScript
- Intersection Observer and CSS-based motion
- Responsive WebP/JPEG project imagery

The site has no framework or build step and is compatible with static hosting such as GitHub Pages.

## Local preview

From the project directory, run:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open [http://127.0.0.1:4173](http://127.0.0.1:4173).
