01 / Context

A clear product presence for a specialist supplier.

Intertekhkorm supplies high-protein ingredients for the animal-feed industry. The website brings the company, product information, and enquiry path into one focused bilingual experience.

The interface gives the technical subject matter room to breathe: strong headings establish orientation, product imagery carries recognition, and concise calls to action make the next step clear.

02 / System

Structured for two languages and straightforward upkeep.

Interface copy is separated into matching Ukrainian and English JSON files. Product details live in their own data source, while shared contact information is maintained through a central configuration file.

The site uses a modular HTML, CSS, and JavaScript architecture without a framework or server-side dependency.

  • Responsive interface across desktop and mobile
  • UA/EN localization
  • Data-driven product catalogue
  • Keyboard-accessible product modals
  • Quotation request forms
  • SEO metadata and sitemap

03 / Technology

Small, durable, and ready for static hosting.

The implementation stays close to the platform: semantic HTML for structure, modular CSS for presentation, and focused JavaScript modules for localization, navigation, forms, and product interactions.

  • HTML5
  • CSS3
  • JavaScript
  • JSON
  • GitHub Pages
  • Cloudflare
