Case study / 01Bilingual B2B website

Intertekhkorm

A responsive corporate website that presents specialized animal-feed ingredients clearly in Ukrainian and English.

Type
Corporate website
Languages
Ukrainian / English
Platform
GitHub Pages
Status
Live website

01 / Overview

A clear digital presence for a specialist supplier.

Intertekhkorm supplies high-protein ingredients for the animal-feed industry. The website brings the company, product information, and enquiry path into one focused bilingual experience.

The work is grounded in direct access to product information: clear headings establish orientation, real product imagery carries recognition, and focused calls to action support quotation requests.

02 / The problem

Technical content needed to remain clear across two languages.

The site needed to explain specialized ingredients without overwhelming visitors, while keeping Ukrainian and English content consistent and making it easy to move from product discovery to an enquiry.

03 / The solution

A modular catalogue with a direct inquiry flow.

Interface copy is separated into matching Ukrainian and English JSON files. Product details live in a dedicated data source, while shared contact information is maintained centrally.

Visitors can move from the catalogue into accessible product modals and quotation forms without losing context.

04 / Implementation

Small, durable, and suitable for static hosting.

The implementation stays close to the platform: semantic HTML for structure, modular CSS for presentation, and focused JavaScript for localization, navigation, forms, and product interactions.

Key features

  • Responsive layouts across desktop and mobile
  • UA/EN internationalization
  • Data-driven product catalogue
  • Keyboard-accessible product modals
  • Quotation request forms
  • SEO metadata and sitemap

05 / Technologies

A focused static-web stack.

  • HTML5
  • CSS3
  • JavaScript
  • JSON
  • Formspree
  • GitHub Pages
  • Cloudflare

06 / Final result

A bilingual website ready for real product enquiries.

The result is a live, responsive corporate website with a maintainable content structure, clear product presentation, and a direct path to request a quotation.
