VSE Homework Agent

A local Python system that analyzes university email, extracts assignments and deadlines, and delivers structured Telegram notifications.

Type
Personal project
Interface
Telegram bot
Runtime
Local macOS service
Language
Python

01 / Overview

A personal system for turning messages into a plan.

VSE Homework Agent is a personal real-world automation project. It monitors university email, extracts useful academic information, stores structured tasks locally, and sends readable updates through Telegram.

It is not a university service, public product, or client commission.

02 / The problem

Assignments arrive as messages, not as a reliable task list.

University email can contain new assignments, deadline changes, submission notices, and schedule updates in inconsistent formats. Important details can be spread across message subjects and bodies.

03 / The solution

A local pipeline from incoming mail to a timely reminder.

The workflow monitors Apple Mail, identifies relevant messages, uses the OpenAI Responses API to extract task details, stores normalized records in SQLite, and sends structured notifications through Telegram.

MailExtractStoreNotify

04 / Implementation

Designed for continuity, not one-off extraction.

A local database keeps detected tasks and supports duplicate prevention. Scheduled jobs handle monitoring, deadline reminders, and daily Telegram summaries, while automatic startup keeps the workflow available after macOS restarts.

Key features

  • Automated email processing
  • AI-assisted task and deadline extraction
  • Duplicate prevention
  • Deadline management and reminders
  • Daily Telegram summaries
  • Local database
  • Automatic startup with macOS

05 / Technologies

A focused local automation stack.

  • Python
  • OpenAI Responses API
  • SQLite
  • SQLAlchemy
  • APScheduler
  • Apple Mail Automation
  • Telegram Bot API

Privacy note: The interface image documents the working project. Names, course identifiers, deadlines, and message content should be anonymized before publication.

06 / Final result

A quieter way to keep academic tasks visible.

The result is a working personal automation that connects email processing, structured AI extraction, local persistence, scheduling, and a compact Telegram interface.

The project remains private and is presented here as a documented personal system rather than a publicly available product.
